# 深潮档案：太平洋异滩

《克苏鲁的呼唤》7 版资源包。改编自 H. P. 洛夫克拉夫特 1919 年发表的公版短篇《大衮》（Dagon）。

1918 年春，旧金山。一名从太平洋上被救回的商船二副在水手医院写完二十七天的手稿，然后从三楼窗口跳了下去。他描述的是一片从海底露出来的泥滩，和泥滩上等待潮水的东西。

配套冒险：[《大衮：深潮之下》](../coc-dagon)。

## 内容

| 类别 | 数量 | 说明 |
|---|---|---|
| 世界模板 | 1 | `pacific_shoal`，含完整时代背景与开场场景 |
| 世界书条目 | 26 | 16 条公开（玩家可查）+ 11 条守秘人专属 |
| 地图 | 1 | 旧金山—太平洋异滩，12 个节点 |
| 地点 | 12 | 8 个旧金山城内 + 4 个海上 |

### 12 个地点

**旧金山**：布里格斯公寓、水手医院、「锚链与钟」酒馆、租船码头、麦克雷船代事务所、海关大楼、多洛雷斯教堂、太平洋地理学会

**海上**：漂流海域、黑色泥滩、独石柱、波吕斐摩斯裂谷

每个地点都写明了可调查物，不是只有一句描述。例如公寓里有六个只抽一半、方向一致朝窗内的烟头——他站在窗边抽，但每次都掐掉，像在练习不往下看。

### 世界书的两层

- **公开（16 条）**：地点与可携带物证。玩家在世界书里查得到，符合「调查员能自己看到」的信息边界。
- **守秘人专属（11 条）**：六名 NPC 的真实动机、大衮与深潮之物的演法、两条核心真相（九人名单、泥滩周期性）。玩家的 `visible_to` 为空时不会被检索到。

这样拆开是有意的：玩家该从对话和掷骰里发现的东西，不该在世界书里直接读到。

## 怎么用

### 配冒险跑

装上本包与 `coc-dagon`，新建游戏时世界选「太平洋异滩：1918」。冒险的 `world_policy` 是 `portable`，`recommended_world_id` 指向本包，装了会自动推荐。

### 单独当沙盒跑

不装冒险包也能用。世界模板自带开场场景（教会街拐角的会面），你可以直接开一局自由调查：手稿是真的还是疯话、九个人去了哪里、那片海域到底有什么，三条线都可以自由推进。

本包提供的实体足够支撑一场 2–3 次的自由团：8 个旧金山地点可以来回跑，4 个海上地点是可重复的（泥滩会周期性出现）。

## 时代考据

- 1918 年 4 月，美国已参战一年，旧金山码头昼夜不停，联合钢铁厂在造驱逐舰。
- 德国袭击舰在南太平洋活动是史实（SMS Wolf、SMS Möwe 都做过），本包虚构了「猎鹰号」。
- 商船水手被俘后「因淡水不足释放部分俘虏」是当时常见的做法，不是编的。
- 旧金山水手医院、多洛雷斯教堂、太平洋地理学会（虚构机构）、海关大楼的位置都符合当时的城区格局。
